# Установка хука

Чтобы Claude Code начал спрашивать подтверждение перед опасными командами, нужно зарегистрировать `approval` как `PreToolUse`-хук.

## 1. Скопируй приложение в `/Applications`

Перетащи `approval.app` из DMG в папку `Applications`. Это нужно, чтобы у бинарника был стабильный путь, который не сломается при обновлениях.

Сейчас приложение запущено по пути:

```
{{APP_PATH}}
```

## 2. Запусти приложение

Открой `approval` из Launchpad. При первом запуске macOS попросит разрешить уведомления — нажми «Разрешить». На странице **Статус** убедись, что индикатор зелёный, сервер слушает.

## 3. Добавь хук в `~/.claude/settings.json`

Открой (или создай) файл `~/.claude/settings.json` и добавь блок `hooks`:

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Bash",
        "hooks": [
          {
            "type": "command",
            "command": "{{APP_BIN}} --hook",
            "timeout": 600
          }
        ]
      }
    ]
  }
}
```

Если файл уже существует и в нём есть другие настройки — добавь только секцию `hooks` к корневому объекту, не перезаписывай весь файл.

Альтернативно — для конкретного проекта только: положи такой же файл в `<project>/.claude/settings.json`.

## 4. Перезапусти Claude Code

Закрой все терминалы с Claude Code и открой заново — настройки подхватываются на старте сессии.

## Проверка

В Claude Code попроси выполнить опасную команду, например:

```
выполни: docker exec ... psql -c "DROP TABLE test"
```

Должно появиться системное оповещение от `approval`. Тапни — откроется окно с деталями. Нажми «Подтвердить» или «Отменить» — Claude Code получит соответствующий ответ.

## Удаление

1. Удалить блок `hooks.PreToolUse` из `~/.claude/settings.json`.
2. Перенести `approval.app` в Корзину.
3. (опционально) удалить данные приложения: `rm -rf ~/Library/Application\ Support/approval`.
